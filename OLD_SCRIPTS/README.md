# OLD_SCRIPTS - Anciens fichiers de backup

Ce dossier contient les anciens fichiers JavaScript/Vue.js/Electron avant la migration vers Tauri + SvelteKit + TypeScript.

**Date de migration**: 2025-11-15

## Contenu

- `src/core/` - Anciens services et modèles JavaScript
- `src/components/` - Anciens composants Vue.js
- `electron/` - Configuration Electron (remplacée par Tauri)
- `vite.config.js` - Ancienne config Vite pour Vue.js
- `vitest.config.js` - Ancienne config Vitest

## Note

Ces fichiers sont conservés uniquement à des fins de référence. Le code actif se trouve dans `src/lib/` (TypeScript) et `src/routes/` (SvelteKit).
